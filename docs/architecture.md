# 独立侧栏建设边界

## 目标

开发者能够把同一套侧栏接入自己的应用，并通过明确的宿主接口提供上下文、工具和操作结果。来源软件只用于追溯代码历史，不作为本库的运行入口、开发依赖或验收前提。

## 当前基线

已具备 Electron 运行时、React 界面、iframe/IPC 桥接、Codex app-server、Claude Agent SDK 和 MCP 配置能力。代码保留部分来源软件的命名及功能分支，尚未完成通用化。

本次保留的功能修复是 Markdown 标识符中的下划线保真，包含本地回归测试。历史宿主集成脚本、截图、日志和上游快照已移至本机独立归档目录 `D:/Project/ai-sidebar-archive/2026-10-23`，不构成本库依赖。

## 建设顺序

1. **独立预览入口**：本库自带最小 Electron 宿主，独立配置目录，支持无登录 UI 预览和显式启用的真实 CLI 验证。
2. **宿主契约**：明确挂载、卸载、尺寸、主题、工作区、选文、附件、工具调用、审批和错误回传；提供类型定义和生命周期约定。
3. **模块边界**：界面、CLI provider、宿主通信和宿主业务适配分别维护。PDF、笔记、图谱等业务能力由适配器提供。
4. **开发者接入**：优先 Electron，再验证支持 WebView 或扩展系统的应用；其他桌面软件通过专门适配器或外置伴随窗口接入。
5. **发布与兼容**：建立版本化 API、独立打包、最小接入示例、升级说明及兼容矩阵。

CLI 承担原生会话与工具执行流程；界面展示实际事件和审批，不用模拟成功结果替代原生执行。

## 测试与测量布局

| 层次 | 验证内容 | 记录指标 |
| --- | --- | --- |
| 本地回归 | 文本渲染、上下文、协议映射、资源边界 | 输出保真、错误分支、稳定复现 |
| 最小宿主集成 | 挂载/卸载、IPC 来源、iframe 来源、主题、焦点 | 首次可交互时间、监听器与进程清理 |
| 原生 CLI | 初始化、流式回答、工具、审批、取消、恢复 | 首段正文延迟、完整回合耗时、错误来源 |
| 宿主适配 | 读取上下文、执行操作、返回结果、工作区切换 | 目标定位准确性、权限边界、状态一致性 |
| 视觉布局 | 320/420/720 像素宽度、浅深色、代码、公式、长对话 | 截断、溢出、滚动、键盘交互 |
| 稳定性 | 网络异常、CLI 退出、长会话、反复挂载 | P50/P95、峰值内存、残留进程、恢复率 |

默认测试不发起模型请求；真实模型测试单独启用。报告区分代码失败、服务额度或认证阻塞、待审批和通过。按 runId、provider、CLI 版本、threadId 和 turnId 关联证据，达到足够样本量后再给出性能分位数。
