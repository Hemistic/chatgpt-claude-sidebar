# 最近会话恢复与数量上限复查（2026-11-04）

修复胶囊切换时总是选择数组中第一个同提供方会话的问题。现在记录实际访问时间，切回提供方时恢复最近访问的真实会话；样例和已归档会话不作为胶囊目标。访问时间随现有会话数据持久化，关闭该会话后按剩余访问记录回退。旧资料没有访问时间时仍使用稳定的已有会话，不改变模型配置。

达到配置的会话数量上限时，“新对话”按钮现在禁用，悬停提示“已打开 N 个会话，请先关闭一个会话”。Codex 端使用已有禁用按钮外观；Claude 继续使用原生按钮。关闭一个空会话后，新建立即恢复可用。不新增常驻界面栏。

两种提供方各有多个打开的会话；生成回复后，通过胶囊双向切换，核对准确会话 ID、模型、思考强度和随机回复标记。重新加载后重复双向切换，全部恢复正确。达到五个会话时按钮禁用，关闭刚创建的空测试会话后恢复为四个且按钮可用。报告渲染异常为 0。
