# 侧栏滚动与置底修复（2026-11-02）

本轮仅处理独立 Electron 侧栏的滚动条、跟随输出和右上角运行圆环。未启动 ArtInFact，未使用 Computer Use。

## 实现

- 消息区保留两侧各 8px 的固定 gutter，左右空白一致。滚动条只在鼠标位于消息区时显示滑块，移开时轨道、滑块及系统箭头均隐藏，悬浮不改变内容宽度。
- 以 sidebar-scroll.js 作为唯一滚动控制者，删除原先“正在输出就重新启用置底”的分支、延时重新跟随和多处竞争写入。React 提交与尺寸变化在绘制前更新底部，不启动反复的平滑滚动。
- 向上滚轮、触摸、键盘及拖动滚动条均能暂停跟随；未点恢复按钮前，新输出不会自动恢复跟随。输入框和可独立滚动的代码区域保留自己的操作。
- 暂停跟随后显示浮动向下按钮，点击立即回到底部并继续跟随；按钮不占常驻纵向空间。切换会话分别记录阅读位置和跟随状态，发送新请求明确回到实时输出。
- 从渲染树中删除 RuntimeCornerLoader 及其专用样式；保留发送／停止操作和消息中的任务信息。
- 两个提供方的滚动条和按钮样式分别在自己的样式表中声明，继续使用各自的主题变量。
